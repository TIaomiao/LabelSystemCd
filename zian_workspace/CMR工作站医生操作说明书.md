> 适用版本：CMR Workstation `v2026.08.15-2`
> 文档更新：2026-08-15
> 适用对象：参与 CMR 影像浏览、轮廓标注、结果复核、报告评分和科研质控的医生与实习生
> 作者 / 工作站维护联系人：Zian，`1980651739@qq.com`
> 使用边界：工作站的 AI 分割、传播、测量和问答结果均需由医生复核，不应脱离原始影像单独作为临床结论。

## 先看这里：3 分钟最小上手指南

### 第 1 步：进入工作站

1. 使用分配给你的账号登录。
2. 进入 **CMR Workstation**。
3. 页面由四个主要区域组成：
   - 顶部：功能模块、当前病例、AI 专家、更新日志和退出登录。
   - 左侧：病例库、数据来源、搜索和标注状态筛选。
   - 中间：影像、勾画、评估或报告评分工作区。
   - 右侧：点击 **AI 专家** 后出现的工作站专家对话栏。

### 第 2 步：找到病例

1. 在左侧 **病例库** 选择正确的数据来源。
2. 可输入登记号、病例号或数据集名称搜索。
3. 可按“全部状态 / 只看已标注 / 只看未标注”筛选。
4. 点击病例卡片：
   - 显示 **导入**：该病例尚未进入 CMR 勾画工作站，点击后等待导入完成。
   - 显示 **打开**：该病例已经导入，可以直接打开。
   - 在评估类模块中显示 **设为当前**：将该病例作为当前评估对象。

> 如果病例卡片显示“未发现 DICOM”，请不要反复点击导入；记录数据来源和页面现象后，通过右上角 **AI 专家 → 数据异常** 反馈。

### 第 3 步：完成一次 4CH 手工标注

1. 顶部选择 **CMR 工作站**，打开目标病例。
2. 在勾画工作站选择 **4CH** 序列，并确认当前 slice 和 phase。
3. 默认先保持浏览模式检查影像：
   - 滚轮：切换 slice。
   - `Shift + 滚轮`：切换 phase。
   - 中键拖动：平移影像。
   - Windows / 普通鼠标右键拖动：调整窗宽窗位。
   - Mac：可使用 `Control + 单击拖动`；也可先选择工具栏中的“窗宽窗位”，再用普通左键拖动。
   - 也可使用工具栏中的平移、缩放、窗宽窗位按钮。
4. 打开右侧 **勾画面板**，选择轮廓类型。
5. 首次勾画优先使用 **连续勾画**：按住左键沿边界描一圈，松开后生成闭合轮廓。
6. 需要时拖动控制点微调；整体偏移可使用 **整体平移**。
7. 点击 **保存轮廓**，等待成功提示。
8. 切换一次 phase 或查看 **Slice / Phase Matrix**，确认当前格子已有轮廓和来源标记。

4CH 当前支持：左房、右房、左室内膜、右室和左室外膜。医生通常只需在任务要求的关键帧完成高质量手工种子；是否继续传播，以本次项目要求为准。

### 第 4 步：保存后再离开

离开病例前至少确认三件事：

- 页面出现保存成功提示。
- 当前 slice / phase 的轮廓仍然可见。
- Slice / Phase Matrix 中对应格子显示轮廓状态。

不要只根据左侧病例卡片的“已标注 N”判断完成度；它是病例级摘要，不等于所有序列、层面、相位和 ROI 都已经完成。

### 第 5 步：遇到问题直接问 AI 专家

点击页面右上角 **AI 专家**，在右侧对话栏选择：

- **功能怎么用**：询问已有功能的入口和操作步骤。
- **报告问题**：反馈按钮、加载、保存或显示异常。
- **功能建议**：提出新的临床工作流需求。
- **数据异常**：反馈病例、序列、DICOM、标注或报告问题。
- **AI 使用体验**：反馈 AI 分割、传播、报告或问答效果。

可以直接粘贴截图，但发送前必须遮挡患者姓名、身份证号、手机号等身份信息。

## 1. 最新版系统能做什么

CMR Workstation 将病例选择、影像勾画、结构化评估、报告评分、科研质控和反馈入口整合在同一个工作台中。

| 模块 | 主要用途 | 建议使用人群 |
|---|---|---|
| CMR 工作站 | 浏览 SAX / 4CH / LGE，手工勾画、AI 分割、传播、ED/ES、脂肪量化和 2D 应变曲线复核 | 标注医生、复核医生 |
| 影像质量 | 记录卷叠、呼吸、血流、金属、运动等伪影并框选区域 | 影像质控医生 |
| 功能评估 | 复核 LV / RV / 心房相关功能和结构指标 | CMR 评估医生 |
| 结构评估 | 记录室壁厚度、运动、室壁瘤和瓣膜表现 | CMR 评估医生 |
| LGE 分析 | 查看 LGE 图像、标注区域及分布模式 | LGE 复核医生 |
| 其他发现 | 记录脂肪浸润、血栓、心包/胸腔积液及其他发现 | 报告医生 |
| 报告评分 | 对照原始报告与 AI 报告，完成多维评分、备注和导出 | 报告评分医生 |
| 心功能验收 | 查看 ED/ES、体积曲线、分割切片及报告真实值对比 | 质控和算法验收人员 |
| 医院病例树 | 按医院、疾病和病例层级浏览历史数据 | 数据复核人员 |
| 实验结果 | 查看人工评分汇总、统计表和实验图表 | 科研和项目负责人 |
| UKB 字段库 | 查阅嵌入的 UKB Data Workstation | 科研人员 |
| AI 专家 | 操作指导、问题追问、截图反馈和问题单沉淀 | 所有使用者 |

医生日常最常用的主线通常是：**病例库 → CMR 工作站 → 手工标注/复核 → 保存 → 必要时进入评估或报告评分**。

## 2. 工作台界面速查

### 2.1 顶部功能区

- 模块页签：切换 CMR 工作站、各类评估、验收和科研页面。
- 上一位 / 下一位：在当前病例列表中切换病例。
- 当前病例：持续显示当前工作对象，切换前建议核对。
- AI 专家：打开右侧工作站专家。
- 更新日志：查看当前版本和近期改动。
- 返回主页：离开工作站返回系统主页。
- 退出登录：结束当前账号会话。

### 2.2 左侧病例库

- 数据来源：选择医院、项目或病例子集。
- 搜索：支持登记号、病例号或数据集名称。
- 标注状态：全部、已标注、未标注。
- 病例卡片：显示 DICOM 数量、常见序列摘要、是否已导入和标注摘要。
- 收起：可折叠病例库，为中间影像区留出更多空间。

### 2.3 中间工作区

中间区域随顶部模块变化。CMR 工作站以影像和勾画为主；评估模块通常是影像、Slice / Phase Matrix 与右侧结构化表单；实验和质控模块以表格、曲线和预览图为主。

### 2.4 右侧 AI 专家

AI 专家会携带当前模块等页面上下文，帮助定位“你正在哪个页面操作”，但不会把页面上下文当成临床结论。对话按账号保存，管理员可查看全部对话和已沉淀问题单。

## 3. 病例选择、导入与切换

### 3.1 导入和打开的区别

- **导入**：将病例登记到嵌入的 CMR 勾画工作站。首次使用该病例时需要执行。
- **打开**：病例已经导入，直接进入影像工作区。
- **设为当前**：在影像质量、功能评估等外层模块中选择当前病例，不代表重新导入 DICOM。

导入过程中不要连续重复点击。若长时间没有完成，记录页面、数据来源和错误提示，交给 AI 专家整理。

### 3.2 切换病例前的检查

1. 当前轮廓或表单是否已保存。
2. 是否仍有 AI 分割或传播任务在运行。
3. 顶部“当前病例”是否与自己准备切换的对象一致。

### 3.3 管理员代看其他医生结果

管理员账号在部分模块可选择查看其他医生的评估或标注结果。普通医生默认只操作自己的会话和数据。代看时先核对“当前查看用户”，避免将复核结果误写到错误对象。

## 4. CMR 影像浏览与勾画

### 4.1 序列与视图

工作站常见序列角色包括：

- **Function | SAX**：短轴 cine，用于 LV / RV 轮廓、ED/ES 和心功能相关量化。
- **4CH**：四腔心 cine，用于关键帧手工标注和时相传播。
- **Tissue | LGE**：延迟强化序列，用于心肌边界、正常参考区、强化区、排除区和 MVO。

序列角色明显错误或缺失时，不要在不确定的情况下随意修改。先截图并通过 **AI 专家 → 数据异常** 说明“当前显示的序列名称、实际打开影像和期望角色”。

### 4.2 常用浏览操作

| 目的 | 操作 |
|---|---|
| 切换 slice | 鼠标滚轮 |
| 切换 phase | `Shift + 鼠标滚轮` |
| 平移影像 | 鼠标中键拖动，或选择“平移” |
| 调整窗宽窗位 | Windows / 普通鼠标右键拖动；Mac 可用 `Control + 单击拖动`；也可选择“窗宽窗位”后左键拖动 |
| 缩放 | 选择“缩放”工具后操作 |
| 精确跳转 | 点击 Slice / Phase Matrix 中的目标单元格 |

进入影像后默认先浏览，确认 slice、phase 和 ROI 后再进入勾画模式，可减少误落点。

### 4.3 各序列可用轮廓

| 序列 | 常用轮廓 |
|---|---|
| Function / SAX | 左室内膜、左室外膜、心室外膜、脂肪壁层、脂肪 ROI（旧）、排除区、右室腔 |
| 4CH | 左房、右房、左室内膜、右室、左室外膜 |
| Tissue / LGE | 左室内膜、左室外膜、remote、强化区、排除区、MVO |

Function / SAX 中，“心室外膜 + 脂肪壁层”用于确定心外膜脂肪范围；“脂肪 ROI（旧）”用于兼容已有病例。LGE 中，remote 用于正常心肌信号参考；强化区、MVO 和排除区会参与科研指标计算。轮廓与数值必须结合原始图像人工复核。

### 4.4 勾画方式

- **连续勾画**：按住左键连续描边，松开后形成闭合轮廓。适合大多数首次手工勾画，建议优先使用。
- **毛刷勾画**：像画笔一样涂出区域并转成可编辑轮廓，适合脂肪、排除区和 scar 等区域。
- **点状勾画**：逐点追加控制点，适合单一边界精细或需要逐点控制的场景。排除区需要保存多个独立区域，因此不使用点状勾画。
- **整体平移**：拖动整条轮廓，处理整体位置偏移。
- **插入控制点**：在边线附近增加控制点，用于局部加密。
- **删除控制点**：点击多余控制点删除。
- **橡皮擦**：拖动删除附近控制点，用于清理局部错误。
- **框选生成 / 涂抹生成**：给 AI 当前帧提示，由 EdgeTAM / SAM 生成当前轮廓；生成后仍需人工调整。

### 4.5 推荐的手工勾画顺序

1. 核对序列、slice 和 phase。
2. 选择轮廓类型。
3. 选择连续勾画或其他合适工具。
4. 完成初始轮廓。
5. 通过控制点微调，检查闭合、穿越和明显偏移。
6. 保存轮廓。
7. 查看成功提示和矩阵标记。
8. 再切换到下一帧或下一病例。

### 4.6 撤销、清空和保存

- **撤销**：优先用于恢复最近一次误操作。
- **清空当前轮廓**：只删除当前选中的 ROI。
- **清空当前帧全部轮廓**：会影响当前 slice / phase 的全部 ROI，点击前必须再次核对当前帧。
- **保存轮廓**：写入工作站并触发相关指标重算。保存前确认轮廓没有自交或明显错误。

如果提示“轮廓存在自交”，请撤销最近修改或重新勾画，不要把异常轮廓继续作为最终结果。

### 4.7 ED / ES

- 可将当前相位手工设置为 **ED** 或 **ES**。
- 可使用 **快速识别 ED/ES**；系统可能基于现有轮廓体积等信息判断。
- 自动识别失败或与影像不符时，以医生人工复核和手工设置为准。
- 设置后应检查 Slice / Phase Matrix 和科研指标是否符合当前相位选择。

### 4.8 Slice / Phase Matrix

矩阵横纵方向对应 slice 和 phase。点击单元格可直接跳转；有轮廓的格子会显示状态，部分结果还会标注手工、AI 或传播来源。

矩阵适合完成三类检查：

- 是否在正确的 slice / phase 上操作。
- 关键帧是否已有目标 ROI。
- AI 或传播完成后，覆盖范围是否符合预期。

### 4.9 心外膜脂肪与多个排除区

心外膜脂肪专项位于 **Function / SAX**。新病例建议按以下顺序操作：

1. 选择 **心室外膜**，勾画完整心室外层边界。
2. 选择 **脂肪壁层**，勾画脂肪外层边界。
3. 如两条边界之间存在不应计入的区域，选择 **排除区**。
4. 使用 **一笔画线、毛刷或 SAM** 生成第一个闭合排除区；完成后可继续画下一个独立排除区。
5. 需要时使用 **撤销上一个**；若本帧全部排除区都需要重做，使用 **清空本帧排除区**。
6. 所有排除区完成后点击 **完成排除**，再保存轮廓并查看科研指标。

脂肪范围按“脂肪壁层以内，扣除心室外膜以内和排除区与脂肪范围的交集”计算。排除轮廓可以画出脂肪范围之外，超出部分不会被重复扣除。

从 `v2026.08.15-1` 起，多排除区的点状微调、微调模式和整轮廓拖拽会保留各自独立身份；编辑第一个排除区不应复制或改变第二个排除区。若仍出现大片灰色覆盖、轮廓数量突然增加或目标排除区以外的区域被修改，请先不要继续保存，立即点击 **复制诊断信息** 并按第 10 节反馈。

## 5. AI 分割与传播补全

### 5.1 两者的区别

| 功能 | 适合场景 | 使用前提 | 完成后要做什么 |
|---|---|---|---|
| AI 分割 | 对整套支持的序列生成初始轮廓 | 序列角色正确，当前模块受支持 | 逐层逐相抽查并人工修正 |
| 传播补全 | 用已保存的高质量种子轮廓补其他相位/层面 | 至少一帧有效且已保存的轮廓 | 检查矩阵覆盖和边界质量 |
| 框选/涂抹生成 | 当前帧单个 ROI 的快速初始化 | 当前 ROI 和提示区域正确 | 立即调整当前轮廓 |

LGE 的快速分割入口当前不作为正式路径；建议使用受支持的 AI 分割后人工修正，或直接手工勾画。

### 5.2 4CH 传播

1. 在目标 slice 的关键 phase 完成高质量轮廓。
2. 点击 **保存轮廓**。
3. 如任务要求，设置 ED / ES。
4. 进入 **传播与 AI** 面板，点击 **传播补全**。
5. 等待任务完成，常见耗时约 1–2 分钟。
6. 在 Slice / Phase Matrix 中逐相检查结果，并对偏移轮廓手工修正。

多 slice 的 4CH 序列完成传播后，要额外确认结果落在哪些 slice；不要把“时相补全”自动理解为所有层面都应使用同一轮廓。

### 5.3 SAX 传播

SAX 传播可能沿 phase 和 slice 补全，完整 cine 常见耗时约 2–3 分钟。建议先复核主要种子轮廓和 ED/ES，再运行传播。完成后至少检查基底部、中部、心尖部和关键相位。

### 5.4 使用 AI 和传播时的注意事项

- 任务运行中不要重复点击同一按钮。
- 切换病例前确认任务已经结束。
- 传播或 AI 结果不是“医生已确认”结果，仍需人工检查。
- EDV、ESV、SV、EF 等数值异常时，先检查 ED/ES 和轮廓，不要直接采用异常数值。
- 正式病例中如需清空大量 AI / 传播结果，应先确认项目流程和权限。

## 6. 报告与科研指标

### 6.1 中文报告

导入病例并完成必要分析后，可进入中文报告区域。修改后点击 **保存报告**，离开前确认保存状态。

### 6.2 科研指标

右侧 **科研指标** 面板用于查看轮廓计算结果。保存轮廓后系统会重新计算；数值变化应与当前序列、ED/ES、ROI 完整度和排除区设置一起解释。

点击 **重算指标** 后，系统会先等待自动保存结束，再保存当前轮廓快照，随后调用后端重算并回填最新结果。看到“指标已按最新轮廓重算（时间）”才表示本次链路完成；不要在保存提示尚未结束时反复点击。

排除区只扣除它与目标脂肪范围的交集。如果排除区完全画在目标范围之外，数值不变化属于正常结果。若排除区明显与目标范围重叠且完成提示已经出现，但数值仍不变化，请点击 **复制诊断信息** 后反馈。

LGE 中 remote、强化区、MVO、排除区的语义不同，不能互相替代。Function 脂肪相关结果也依赖心室外膜、脂肪壁层和排除区质量。

### 6.3 2D 应变与追踪验证

在 CMR 工作站右侧打开 **科研指标**，可查看 **2D 应变与追踪验证**：

- **4CH**：至少保存两个 phase 的左室内膜后，可显示 GLS proxy 峰值、ED / ES、可用相位数和相位曲线。
- **SAX**：左室内膜用于 GCS proxy，左室内膜与左室外膜共同用于 GRS proxy；保存多个 phase 后可查看对应曲线。
- **运行追踪验证**：比较相邻的手工或手工修正相位，并显示可比较相位对、Dice、边界误差和平均位移。
- 只勾画不相邻的 ED 与 ES 时，“人工相邻相位对”为 0 属于正常结果；如需追踪对照，应再完成一组相邻 phase 的手工轮廓。

应变曲线会随已保存轮廓和 ED / ES 设置更新。复核时先确认当前主视图是目标 4CH 或 SAX，再核对可用相位数与实际已保存轮廓是否一致。

### 6.4 结果复核原则

- 先看原始影像，再看轮廓，最后看数值。
- 数值与影像不一致时，返回对应 slice / phase 检查。
- AI、传播和历史导入的来源标记不能替代人工复核。
- 任何异常值都应先排除相位、序列角色和轮廓问题。

## 7. AI 专家：操作说明书 Plus 与问题反馈入口

### 7.1 在哪里打开

进入 CMR Workstation 后，点击右上角 **AI 专家**。侧栏位于主工作区右侧，再次点击或点击关闭按钮可收起。

### 7.2 专家与超高

- **专家**：适合常规操作路径、单个错误提示和简单反馈，建议默认使用。
- **超高**：适合跨模块问题、较复杂的医学概念转工程描述或需要更完整追问的情况。

### 7.3 AI 专家能做什么

- 根据当前页面说明已有功能在哪里、需要什么前置条件、如何检查结果。
- 将医生自然语言转换成页面、序列、slice、phase、ROI、按钮、实际表现和期望表现。
- 对 bug、功能建议、数据异常和 AI 使用体验逐步追问。
- 信息足够时沉淀为问题单，供管理员后续查看和处理。
- 保存你自己的历史对话，便于继续追问。

### 7.4 AI 专家不能做什么

- 不能替医生作出诊断或治疗建议。
- AI 分割、测量和报告需要按当前项目流程由医生复核确认。
- 不能在医生对话中直接修改病例、标注、数据库、权限或服务器代码。
- 不能从截图中判断截图之外的操作步骤。

### 7.5 如何提问最有效

操作咨询示例：

> 我现在在 4CH 勾画页，想标 ED 和 ES 两帧的左室内膜，应该依次点哪里？保存后怎么确认成功？

Bug 反馈示例：

> 页面：CMR 工作站 4CH。操作：连续勾画右室内膜后点击保存。实际：提示成功，但刷新后当前轮廓消失。期望：刷新后仍显示刚保存的轮廓。这个现象连续出现 2 次。

数据异常示例：

> 当前病例卡片显示有 DICOM，但打开后 4CH 为空，SAX 可以正常查看。请帮我确认还需要记录什么信息。

AI 使用体验示例：

> 我保存了一个 4CH 手工种子后运行传播。实际结果跨到了不应传播的 slice，当前任务只需要同一 slice 的时相补全。希望传播范围可限定为当前 slice。

### 7.6 截图与隐私

- 可粘贴或选择 PNG、JPEG、WebP 图片。
- 单张截图不超过 8 MB，每条消息最多 4 张。
- 截图发送前必须遮挡患者姓名、身份证号、手机号等身份信息。
- 截图用于识别页面、按钮、状态和错误提示，不用于远程诊断。

### 7.7 历史对话和问题单

- 左上方历史下拉框可切换自己的对话。
- “+”按钮新建对话，建议不同问题分开建立。
- 回答下方可标记“有帮助”或“没有解决问题”。
- 信息充分时，侧栏会显示“已沉淀问题单”。
- 对话按账号隔离；管理员可在反馈面板查看全部对话和问题单。

## 8. 各功能模块详细说明

### 8.1 影像质量

用于检查 SAX、4CH、LGE 的图像质量，可在原始图像和增强/对照视图之间切换，记录卷叠、呼吸、血流/流动、金属和运动伪影，并在影像上框出伪影区域。完成后点击保存。

### 8.2 功能评估

用于记录左室、右室和心房的功能与结构评价，包括 LVEF、LVEDV、LVEDD、室间隔厚度、RVEF、RVEDV、LAV 和 RAV 等。支持影像浏览、测量工具、Slice / Phase Matrix 和结构化选项。保存前核对当前病例和测量单位。

标准指标行会固定展示；当前病例的 AI 或报告来源没有该值时显示“未计算”，而不是隐藏整行。不同病例数值完整度不同是数据来源差异，不代表某台电脑缺少功能。若同一版本、同一病例在两台电脑显示的指标行仍不一致，请两边分别点击 **复制诊断信息** 后反馈。

### 8.3 结构评估

主要包括：

- LV 心肌厚度：正常、增厚、变薄及具体类型和部位。
- 心脏运动及功能：室壁运动、局部部位和室壁瘤。
- 瓣膜形态及功能：狭窄、返流及程度。

页面支持影像浏览和测量。填写完成后点击保存。

### 8.4 LGE 分析

支持单视图/双视图、标注框显示/隐藏、当前图像隐藏、前后图像切换和保存。对于已框选区域，可记录心内膜下、心肌中层、心外膜下等分布模式。隐藏图像仅用于当前分析流程时，应确认不会误排除需要复核的图像。

### 8.5 其他发现

用于记录心肌内脂肪浸润、血栓及位置/大小/活动度、心包积液、胸腔积液和其他发现。可配合测量工具使用，完成后保存。

### 8.6 报告评分

报告评分页面用于对照原始报告和 AI 生成报告，查看不同报告版本，完成评价维度、评分和修改意见。部分内容会自动保存；离开前仍应确认页面显示“已自动保存”或提交成功。需要批量结果时可创建 Excel 导出任务，并选择只导出已评分病例或全部病例。

### 8.7 心功能验收

用于项目级结果验收，可按运行批次、中心和病例搜索，查看：

- 计算指标与报告真实值及差值。
- ED / ES 自动检查对比。
- SAX LV 体积曲线。
- SAX、4CH、LGE 序列预览。
- ED / ES 分割切片和测量图。
- 所有 SAX phase 的抽样结果。

该模块主要服务于科研和算法质控，不替代医生在原始影像上的最终复核。

### 8.8 医院病例树

按照医院 → 疾病 → 病例 → 功能模块浏览数据，适合按疾病项目回看病例。若列表没有更新，可使用刷新入口；不要仅依赖本地缓存判断病例是否已正式入库。

### 8.9 实验结果

用于查看人工评分汇总、评分人覆盖度、维度对比、指标统计表和实验图表。可切换评分病例库。该页用于项目统计和科研复盘，不是单病例临床报告页。

### 8.10 UKB 字段库

嵌入 UKB Data Workstation，可在当前页面或新标签页打开。字段含义和数据处理流程由对应项目维护者负责；遇到接口或字段问题可在 AI 专家中选择“数据异常”反馈。

## 9. 常见问题与处理

### 9.1 搜不到病例

1. 检查数据来源是否正确。
2. 清除“只看已标注 / 未标注”等筛选。
3. 使用完整登记号或病例号搜索。
4. 点击刷新。
5. 仍找不到时通过 AI 专家反馈数据来源、搜索方式和页面结果，不要发送患者姓名。

### 9.2 点击导入后没有进入影像

- 不要连续重复点击。
- 记录是否一直显示“导入中”、是否出现错误提示。
- 刷新病例库后检查按钮是否变成“打开”。
- 仍失败时选择 **AI 专家 → 报告问题**。

### 9.3 保存后轮廓不见了

先确认当前病例、序列、slice、phase 和 ROI 是否与保存时一致；再检查 Slice / Phase Matrix。若刷新后仍丢失，记录保存提示、复现次数和具体操作路径，按 bug 反馈。

### 9.4 提示轮廓自交

撤销最近一次修改，检查边界是否穿越、回折或重叠；必要时重新勾画。后端拒绝异常轮廓是为了避免错误结果进入后续计算。

### 9.5 AI 分割或传播长时间运行

不要重复启动任务。记录模块、序列、任务类型和当前进度；等待合理时间后仍不结束，再通过 AI 专家反馈。切换病例前确认任务状态。

### 9.6 指标出现明显异常

依次检查：当前病例 → 序列角色 → ED/ES → 关键 ROI → slice/phase 覆盖 → 排除区。不要仅修改数值表面结果；如果轮廓和相位均无明显问题，再反馈为计算或数据异常。

### 9.7 应变面板没有数字或一直计算中

先确认当前打开的是目标 4CH 或 SAX，并至少有两个可用于计算的已保存 phase。点击 **重算指标** 后检查可用相位数；追踪验证只比较相邻人工相位，因此非相邻 ED / ES 显示 0 对是正常结果。若按钮持续显示“计算中”，不要重复点击，记录当前序列、已画 phase 数和页面状态后反馈。

### 9.8 AI 专家截图上传失败

1. 确认图片为 PNG、JPEG 或 WebP。
2. 确认单张不超过 8 MB、每条不超过 4 张。
3. 尝试刷新页面后重新上传一张较小截图。
4. 截图仍失败时可先发送文字，并说明入口、文件类型、大小以及是否所有图片都失败。

### 9.9 AI 回答理解错页面

在文字第一句明确写目标页面，例如：“我要反馈的是实验结果页，不是右侧 AI 专家面板。”文字点名的页面优先于截图中偶然出现的侧栏或背景。

### 9.10 排除区保存后科研指标没有变化

1. 确认排除区与“脂肪壁层以内、心室外膜以外”的目标区域确实有重叠。
2. 点击 **重算指标** 后等待出现带完成时间的提示，不要连续点击。
3. 记录重算前后的目标指标值和排除区数量，不发送患者身份信息。
4. 若仍不变化，先不要换电脑或刷新；点击 **复制诊断信息**，再按第 10 节反馈。

### 9.11 排除区微调后出现大量灰色轮廓

当前版本已修复多排除区在点状微调、微调模式和拖拽时被当成新增副本的问题。遇到类似现象时先点击 **撤销**，不要继续保存异常轮廓；随后记录“修改的是第几个排除区、修改前后排除区数量、使用的修改工具”，并复制诊断信息。若页面版本早于 `v2026.08.15-2`，先刷新到新版本再复测。

### 9.12 功能评估缺少群教程中的指标

先看对应行是否显示“未计算”。这表示当前病例的 AI 与报告来源均没有该值，不是电脑品牌或屏幕大小导致。若整行完全消失，记录当前版本和缺少的指标名，并点击 **复制诊断信息**；不要用另一病例的截图直接判断当前病例也应该有相同数值。

## 10. 一条高质量反馈应包含什么

发生问题后，优先保持当前页面，不要立即刷新、换电脑或重新打开病例。先在 CMR 勾画页或功能评估页点击 **复制诊断信息**。它会生成版本、浏览器、平台、窗口大小、匿名工作状态、Study / Series ID、slice / phase、工具模式、排除区数量、保存/重算状态和最近操作；不会包含患者姓名、登记号、DICOM 描述、图像、服务器路径或登录 token。

建议按下面的顺序写：

1. **页面/模块**：在哪里发生。
2. **医学任务**：原本想完成什么。
3. **操作步骤**：点了什么，选了哪个序列、slice、phase 或 ROI。
4. **实际表现**：具体哪里不对。
5. **期望表现**：正常应该怎样。
6. **影响范围**：单个病例、部分病例还是所有病例。
7. **复现情况**：必现、偶发或首次出现。
8. **验证标准**：修复后怎样证明问题解决。
9. **诊断信息**：粘贴“复制诊断信息”生成的完整内容。

可直接复制下面的群反馈模板：

> CMR 问题反馈
> 发生时间：
> 页面/模块：
> 发生前操作（按顺序写）：
> 预期结果：
> 实际结果：
> 出现次数：必现 / 偶发 / 第一次
> 是否刷新、重新打开或换电脑：
> 截图：仅截功能区域，已遮挡身份信息
> 诊断信息：点击页面“复制诊断信息”后粘贴

排除区问题额外写三项：修改的是第几个排除区、修改前后排除区数量、排除区是否与目标脂肪 ROI 重叠。指标问题额外写重算前后的指标名和数值；没有值时写“未计算”，不要猜测或补填。

不要只写“分割不准”“不好用”或“页面有问题”。可以改写为：

> 在 4CH 当前 slice 的 ED 帧运行传播后，右室内膜在后续多个 phase 明显越过室间隔；3 个测试病例中出现 2 个。希望传播后保持在当前 slice，并能在保存前逐相预览和修正。

## 11. 数据安全与使用边界

- 不在 AI 对话中输入患者姓名、身份证号、手机号或其他直接身份信息。
- 截图前遮挡身份信息；不上传完整 DICOM 或无关病例资料。
- 反馈截图只保留发生问题的影像、工具和指标区域；裁掉病例列表、登记号、姓名、检查号和其他身份区域。完整工作站截图即使只用于群聊，也可能暴露患者信息。
- 不用他人账号代替本人完成标注或评分。
- 不在不确定当前病例、slice、phase 时执行清空、批量 AI 或传播。
- AI 输出、自动测量和传播结果必须人工复核。
- 发现病例错配、序列错配或标注归属异常时，应停止继续写入并反馈管理员。

## 12. 术语速查

| 术语 | 含义 |
|---|---|
| Study | 一次检查或工作站中的一个病例检查记录 |
| Series | 同一采集序列的一组影像 |
| Slice | 层面 |
| Phase | 心动周期相位 |
| ED | 舒张末期 |
| ES | 收缩末期 |
| ROI / 轮廓 | 在影像上标记的结构或区域 |
| SAX | 心脏短轴序列 |
| 4CH | 四腔心长轴序列 |
| LGE | 延迟钆增强序列 |
| remote | LGE 中用于正常心肌信号参考的区域 |
| enhanced | 强化区域 |
| MVO | 微血管阻塞相关标记区域 |
| exclude | 从计算或目标区域中排除的区域 |
| 心室外膜 | 心外膜脂肪专项的内层边界 |
| 脂肪壁层 | 心外膜脂肪专项的外层边界 |
| GLS / GCS / GRS | 纵向、周向和径向应变相关指标 |
| Dice | 两个分割区域重合程度的指标，越接近 1 表示重合越高 |
| AI 分割 | 模型根据影像自动生成初始轮廓 |
| 传播补全 | 根据已有种子轮廓补充其他 phase / slice |

## 13. 离开病例前的 20 秒检查

- [ ] 当前病例正确。
- [ ] 当前序列、slice 和 phase 正确。
- [ ] 目标 ROI 已完成并人工检查。
- [ ] ED / ES 与任务要求一致。
- [ ] 已点击保存并看到成功提示。
- [ ] Slice / Phase Matrix 中对应格子已有结果。
- [ ] AI / 传播任务已结束，关键结果已抽查。
- [ ] 没有把异常指标直接当成最终结果。
- [ ] 需要反馈的问题已通过 AI 专家记录。
- [ ] 遇到异常时已先复制诊断信息，没有先刷新或换电脑破坏现场。
