# 室间隔/游离壁曲率比：手工版 V1 准备说明

## 当前范围

- 仅支持 `cine_sax`。
- 医生手工选择 slice 和 phase，并手工放置 J1、J2、M1、M2。
- 使用目标帧索引中的 PixelSpacing，将像素点转换为图像平面毫米坐标。
- 计算两个三点圆的半径、曲率及带符号曲率比 RC；同时保留绝对值供几何核对。
- 结果仅写入 `measurement.research.curvature`，标记 `clinical_grade=false` 和 `confirmation_status=draft`。
- 反弓按负值处理；不做 0.67 阈值、SBP、RVSP、自动选层、自动选相位、自动轮廓吸附或自动 M 点。

## 医生操作口径

- 序列：短轴电影（SAX cine）。
- 层面：左室长轴基底三分之一内的中间层，要求左室心肌环完整，并避开二尖瓣环、流出道、乳头肌和粗大肌小梁干扰。
- 时相：正式测量优先取左室腔面积最小的收缩末期帧；医生在界面上手工确认该帧。
- J1：室间隔与左室前壁的上前侧交界点；J2：室间隔与左室下壁的下后侧交界点。
- M1：J1-J2 之间室间隔内膜弧的中央点；M2：J1-J2 之间左室游离壁内膜弧的中央点。第一版均由医生手工放置，不强制解释为数学上的 50% 弧长点。
- 四点均放在左室心内膜血池边界，允许医生拖动修正。

## 输入与持久化

四点保存在 function `ContourSet` 顶层，独立于普通分割轮廓：

```json
{
  "curvature_landmarks": {
    "slice_index": 3,
    "phase_index": 12,
    "j1": {"x": 120.5, "y": 98.2},
    "j2": {"x": 123.1, "y": 176.4},
    "m1": {"x": 101.2, "y": 137.6},
    "m2": {"x": 176.8, "y": 138.4},
    "method": "manual_four_point"
  }
}
```

旧客户端、普通轮廓保存和模型任务无论是否携带该字段，都必须保留服务器中的最新四点。只有专用 `PATCH /contours/{series_id}/curvature` 可以更新四点或用 `landmarks: null` 清除；四点不能保存到 LGE module。

## 几何与 QC

- 三点曲率：`k = 2 * abs(cross) / (a * b * c)`。
- 比值绝对值：`RC_magnitude = abs(k_IVS) / k_FW`。
- 符号不依赖屏幕方向：M1/M2位于J1-J2弦两侧时RC为正；M1在线时为0；M1跨弦后与M2同侧时为反弓，RC为负。
- 室间隔三点共线且 M1 投影位于 J1-J2 线段内时，按平坦弧处理：曲率为 0、半径为 `null`，界面可显示为无穷大。
- 游离壁平坦、重复点、M 点投影越过 J1-J2 端点、点越界、帧不存在或 PixelSpacing 无效时，不输出比值。
- 输出形态分类 `non_inverted / flat / inverted`；正值只表示“未反弓”，不能直接解释为正常。
- 所有输出只能包含有限数值或 `null`，禁止 NaN/Infinity。

## 已确认事项与样本边界

- 省医院补充资料已经确认基底段中间层、四点放置和反弓负号规则；第一版接受全手工操作。
- 当前资料包含一个完整四点示例，以及变平、反弓的三点形态示例。足以开发和界面联调，但不能替代观察者一致性或临床准确性验证。
- 自动弧长中点、自动选层和自动选相位留待分割/跟踪性能成熟后实施，不作为手工 V1 的交付条件。

## 前端恢复与实现

最终入口位于嵌入式 CMR Workstation 的 Function/SAX viewer。原始 React 工程无法从 Git、本机备份、`LabelSystem copy`、`LabelSystem-dev` 或服务器归档恢复，因此采用“冻结旧运行时 + 独立可维护曲率插件”的兼容方案，避免重写或破坏现有分割、传播和报告功能。

这里有两层前端：

- `frontend/src` 是外层 LabelSystem 源码，负责病例列表、功能页和嵌入工作站。
- `/cvi-workstation-app/...` 实际显示的是内层 CMR Viewer；原 Viewer 成品保存为 `apps/web/legacy-runtime`，新曲率功能源码位于 `apps/web/src`。

曲率插件提供 Function/SAX 入口、四点顺序放置、拖动、撤销、拟合圆/椭圆叠加、实时 QC、正/零/负 RC、草稿保护、专用保存和刷新重载。普通轮廓保存不能覆盖曲率四点。

默认构建输出到 `apps/web/.vite-build`，不会修改当前服务器页面。安装构建需要单独部署决定；构建过程会保留服务器当前 legacy bootstrap 和 cache-buster，防止回退其它工作站功能。

## 临床试用前仍需完成

- 在去标识化真实病例上完成浏览器交互验收并决定安装构建。
- revision/ETag 冲突控制，避免两位医生同时修改同一曲率时最后写入覆盖。
- 当前轮廓级元数据会记录最后修改人和时间；曲率专属的确认动作、完整历史和电子签名留待后续。
- 系统优先读取所选帧原始 DICOM PixelSpacing；读取失败时回退索引值并明确显示 `unverified` 警告。
- 医生金标准病例、观察者内/观察者间一致性验证。
