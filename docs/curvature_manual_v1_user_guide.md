# 室间隔曲率手工测量 V1 使用说明

## 功能用途

本功能用于在心脏磁共振短轴电影图像上，通过手工放置四个点，计算室间隔和左室游离壁的半径、曲率及曲率比 RC。

第一版只完成几何测量，不输入收缩压，不估算 RVSP，也不使用 0.67 阈值自动判定阳性。当前结果按研发草稿管理，不能单独作为临床诊断结论。

## 测量前准备

1. 进入 LabelSystem 的“工作站”，打开目标病例的 Function 模块。
2. 主图选择 SAX cine（左室短轴电影）序列。
3. 选择左室基底三分之一内的中间层：该层应显示完整的左室心肌环，并尽量避开二尖瓣环、左室流出道、乳头肌及粗大肌小梁干扰。
4. 在该层电影中选择左室腔面积最小的一帧，作为收缩末期帧。

## 四点测量流程

1. 点击主图上方的“曲率测量”。
2. 核对面板中的序列、层号和相位号；需要从当前图像开始时，点击“当前帧重新测量”。
3. 按顺序在左室心内膜血池边界放置四点：
   - J1：室间隔与左室前壁的上前侧交界点。
   - J2：室间隔与左室下壁的下后侧交界点。
   - M1：J1 与 J2 之间室间隔内膜弧的中央点。
   - M2：J1 与 J2 之间左室游离壁内膜弧的中央点。
4. 放点后可直接拖动任一点微调；也可选择点后重新点击图像、清除选中点或撤销上一步。
5. 核对图上的 J1/J2 参考弦、两条弧线和拟合圆，并查看右侧实时计算结果。
6. 几何检查通过后，点击“保存四点与结果”。看到“已保存”后，本次测量完成。

## 结果解释

- R IVS：室间隔三点拟合圆半径，单位 mm。
- R FW：左室游离壁三点拟合圆半径，单位 mm。
- C IVS：室间隔带符号曲率，单位 mm⁻¹。
- C FW：左室游离壁曲率，单位 mm⁻¹。
- RC：C IVS / C FW。

RC 的符号规则：

- RC > 0：室间隔未反弓。正值不等于“正常”，还需结合形态和临床资料。
- RC = 0：室间隔近似完全变平。
- RC < 0：M1 与 M2 位于 J1-J2 参考弦同侧，按室间隔反弓记录。

## 常见提示

- “当前显示帧与四点帧不同”：返回原层面和相位，或点击“当前帧重新测量”。
- “四点尚未放置完整”：补齐 J1、J2、M1、M2。
- “M1/M2 未位于对应弧段中央区域”：调整中央点，使其投影位于 J1-J2 两端之间。
- “PixelSpacing 来源未核验”：毫米半径和曲率采用了索引中的回退值，当前结果只作研发预览，应换数据或核对 DICOM 元数据后再使用。
- 几何检查未通过时，系统不会允许保存有效 RC。

## 修改和清除

- 再次打开“曲率测量”会读取已保存四点，可拖动修改后重新保存。
- “恢复已保存”用于放弃尚未保存的修改。
- “清除已保存”只删除曲率四点及对应曲率结果，不删除普通心功能轮廓。

## V1 验收建议

上线后分别用正常弯曲、室间隔变平、室间隔反弓的去标识化病例完成一次全流程检查，确认：

1. 四点可以放置、拖动和撤销。
2. 正常/未反弓结果为正，完全变平接近 0，反弓结果为负。
3. 保存后刷新页面仍能恢复四点和结果。
4. 普通轮廓保存不会覆盖曲率四点。
5. 清除曲率后普通轮廓保持不变。
